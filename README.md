# 261117 게임만들기

네모정원 개발 프로젝트입니다.

숫자 힌트를 보고 그림을 완성하는 네모로직 게임입니다. 한 화면에서 플레이하며, 드래그 입력과 연결 칸 수 표시, 난이도별 공유 랭킹, Codex CLI를 통한 AI 해설을 제공합니다.

## 퍼즐 구성

| 난이도 | 크기 | 문항 수 |
| --- | --- | ---: |
| 쉬움 | 5×5 | 104 |
| 보통 | 10×10 | 103 |
| 도전 | 15×15 | 103 |
| 어려움 | 20×20 | 103 |
| 매우 어려움 | 25×25 | 103 |

총 **516문항**입니다. 그림·문자·무늬와 배치 변형을 포함합니다. 매우 어려움은 거북이, 로봇, 열기구, 선물, 집, 성, 카메라, 배낭, 여행가방, 버스, 기차, 파인애플, 사과, 배, 도토리, 주전자, 컵케이크, 화분, 버섯의 **19가지 그림 종류**로 구성됩니다.

각 문항의 정답이 하나인지 검사했습니다. 매우 어려움은 기본 행·열 배치 추론이 멈춘 뒤 후보 분기가 필요한지 검사했습니다. 더 강력한 모든 추론 기법으로도 반드시 가정이 필요하다는 뜻은 아닙니다.

새 퍼즐은 이미 본 문항을 피하고 그림 종류도 연속으로 반복하지 않도록 선택합니다. 이전 문항으로 시작한 플레이를 처리하기 위한 자료는 `puzzle-legacy.json`에 별도로 보관합니다.

## 실행

Python 3.10 이상을 권장합니다. 게임 서버에는 외부 Python 패키지가 필요하지 않습니다.

```sh
python jump-game/server.py
```

브라우저에서 <http://127.0.0.1:8765/>를 엽니다. 같은 와이파이의 다른 기기는 서버가 출력하는 `Wi-Fi URL`로 접속합니다. 서버를 실행하는 PC를 켜 두어야 합니다.

`index.html`만 직접 열어도 개인 모드로 퍼즐을 풀 수 있습니다. 공유 랭킹과 AI 해설은 서버를 통해 접속해야 사용할 수 있습니다. GitHub에 소스를 올리는 것만으로 서버나 AI가 배포되지는 않습니다. GitHub Pages 같은 정적 호스팅에서는 서버 기능이 실행되지 않습니다.

## 조작

- 왼쪽 드래그: 여러 칸 채우기. 채운 칸에서 시작하면 지우기.
- 오른쪽 드래그: 빈칸 `×` 표시.
- 방향키 / Space / X: 칸 이동 / 채우기 / 빈칸 표시.
- 한 수 취소: 마지막 클릭이나 드래그 전체 되돌리기.
- 칸에 커서 올리기: 게임판 오른쪽에서 가로·세로 연속 칸 수와 상하좌우 전체 연결 칸 수 확인.
- 이름 보기: 숨은 그림의 이름 공개.

힌트 숫자 하나마다 테두리가 있어 `[17]`과 `[1] [7]`을 구분할 수 있습니다.

## 랭킹과 AI

완성 시간, 닉네임, 그림, 힌트·정답 확인·AI 사용 횟수가 SQLite에 저장됩니다. 일시정지 시간은 제외합니다. 같은 서버에 접속한 플레이어끼리 난이도별 랭킹을 공유하고, 다른 PC의 별도 서버와는 기록이 분리됩니다.

AI 해설에는 서버 PC의 **Codex CLI 설치와 로그인**, 인터넷 연결이 필요합니다. 로그인 정보와 API 키는 저장소에 포함하지 않습니다. 방문자가 Codex를 설치할 필요는 없습니다.

서버가 다음 수를 검사하고 Codex CLI가 한국어로 설명합니다. 확정 수, 정답 대조 수정, 가정 후보를 구분하며, 사용자가 적용 버튼을 눌러야 칸이 바뀝니다. 동일 상태의 응답을 재사용하고, 한 번에 하나씩 처리하며 서버 전체 시간당 30회와 플레이별 20회 제한을 적용합니다. 인증된 대회용 부정행위 방지 시스템은 아닙니다.

## 인터넷 공개 공유

Windows에서는 Cloudflare의 공식 공유 프로그램을 다운로드한 뒤 실행할 수 있습니다.

```sh
python scripts/download_cloudflared.py
python jump-game/public_share.py
```

출력된 HTTPS 주소를 공유하면 가입 없이 접속할 수 있습니다. 이는 임시 주소이며 서버와 공유 프로그램이 실행 중일 때만 유효합니다. 재실행하면 주소가 바뀔 수 있습니다. 고정 주소나 상시 운영에는 별도의 호스팅 설정이 필요합니다.

## 검사

Node.js 22 이상과 Python으로 기본 기능을 검사합니다.

```sh
node jump-game/test_puzzle_library.cjs
node jump-game/test_ai_client.cjs
node jump-game/test_shared_client.cjs
python jump-game/test_shared_server.py
```

테스트는 임시 데이터베이스를 사용하며 실제 랭킹을 변경하지 않습니다. AI 클라이언트 테스트는 응답을 모의 처리하므로 계정 사용량을 소비하지 않습니다. 개발 과정에서는 별도로 실제 Codex CLI 왕복 호출도 확인했습니다.

## Windows 실행 파일 빌드

배포된 예전 ZIP과 실행 파일은 이 저장소에 포함하지 않습니다. 아래 명령은 현재 소스로 새 파일을 만듭니다.

```sh
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements-dev.txt
python scripts/download_cloudflared.py
python jump-game/build_portable.py onefile
```

결과는 `jump-game/portable-build/onefile/NemoGarden.exe`입니다. Windows에서 빌드하면 Windows 64비트용으로 만들어집니다. 실행하는 PC에 Python을 별도로 설치할 필요는 없으며, AI 해설만 그 PC의 Codex 설치·로그인이 필요합니다. 실행 파일의 랭킹은 `%LOCALAPPDATA%\NemoGarden\shared-rankings.sqlite3`에 저장됩니다.
